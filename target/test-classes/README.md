# Pruebas

Dos grupos de pruebas:

1. **Pruebas de la biblioteca (Desafío 1):** grafo vacío, un vértice, conexos y no conexos, con y sin ciclos, vértices inexistentes o sin aristas, pesos iguales y caminos alternativos de igual costo, y casos borde de cada algoritmo.
2. **Pruebas del sistema (Desafío 2):** casos orientados a la solución de telecomunicaciones (ruteo, cableado, fallas, CDN y consultas propias).
